# TC-1401: Population forms in a state clause

## Description

Verify FR-376-AC-9: the six population forms are admitted in a state-clause body with FR-376's meaning.

## Test Procedure

Check and evaluate each form of FR-376-AC-9 in a state-clause invariant over a model whose population has authored maximum 3, at states with zero, one and two matching objects.

## Expected Results

Each type, value and undefined outcome matches FR-376-AC-9; none refuses `unsupported_construct`.

# TC-1202: Native-runtime items settle independently

## Description

Native-runtime items settle independently. Scope: FR-550-AC-3.

## Test Procedure

Select three items whose second refuses; then a violated and an incomplete item.

## Expected Results

Three dispositions in selection order, the first and third equal to their solo runs, overall category refusal; the second request's overall category is incomplete.
